# Project Source Resolution Is Demand-Driven

Project open publishes lightweight Canvas source descriptors and does not compute exact saved-file hashes. Workbench source maintenance follows Folder Disclosure, waits for Canvas interaction idle, skips unknown media, and uses viewport distance only as priority; offscreen disclosed sources continue resolving. The sole membership exception is a known video path with a persisted Feedback Moment: Runtime loads only that path's ancestor closure and publishes a lightweight Feedback maintenance descriptor while leaving the video undisclosed and unhashed. Runtime authorizes that exact descriptor through the same one-at-a-time source-resolution lane, without admitting other hidden media. Runtime turns each exact SHA-256 result into a session-local Project Source Lease reused by raw Range, image-preview, and video-preview consumers through cheap file-snapshot validation. Path changes invalidate only the affected lease and derived image cache, while an unlocalized watcher rescan may clear the derived image cache without scanning Project content. This keeps project opening independent of total media bytes, preserves Canvas ADR 0007's separation of maintenance membership from viewport presentation, and avoids persistent source caches, whole-Project background scans, and additional timers. ADR 0079 and Canvas ADR 0007 define the Feedback-video exception and its retry semantics.
