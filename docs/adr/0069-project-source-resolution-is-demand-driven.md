# Project Source Resolution Is Demand-Driven

Project open publishes lightweight Canvas source descriptors and does not compute exact saved-file hashes. Workbench source maintenance follows Folder Disclosure, waits for Canvas interaction idle, skips unknown media, and uses viewport distance only as priority; offscreen disclosed sources continue resolving. Runtime admits one exact SHA-256 digest at a time and turns its result into a session-local Project Source Lease reused by raw Range, image-preview, and video-preview consumers through cheap file-snapshot validation. Path changes invalidate only the affected lease and derived image cache, while an unlocalized watcher rescan may clear the derived image cache without scanning Project content. This keeps project opening independent of total media bytes, preserves Canvas ADR 0007's separation of maintenance membership from viewport presentation, and avoids persistent source caches, whole-Project background scans, and additional timers.
